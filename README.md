# Bohemia Photos — программа с окном

При запуске программа спрашивает, что нужно сделать:

1. **Proforma / Invoice → Excel.** Кнопкой «Добавить…» выбрать один или несколько PDF (или Excel-выгрузку заказа),
   при желании добавить один или несколько прайс-листов для сверки, указать файл отчёта → «Сделать Excel».
   В отчёте лист «Позиции» (код, описание, кол-во, цена, скидка, сумма, проверка кол-во × цена = сумма,
   из какого прайса взята цена и сверка с ней) и лист «Документы» (номер, дата, валюта, сумма строк и итог).
   Код ищется в прайсах точно, по короткому коду Bohemia или по началу кода (Guzzini: `1793.00` → `179300156`).
2. **Фото из каталогов.** Добавить один или несколько прайсов (бренд — Bohemia или Guzzini — определяется
   по кодам, его можно поменять кнопкой «Сменить бренд»), выбрать папку с каталогами (каталоги разных брендов
   могут лежать вместе) и папку результата → «Вырезать фото». Для каждого прайса — своя подпапка с `photos`
   и `report.xlsx`. У Guzzini к базовому коду каталога (`281976`) в прайсе добавлен цвет (`28197682`);
   если в каталоге есть образец нужного цвета, берётся он.

## Как получить .exe
**Вариант 1, GitHub (ничего не ставить на компьютер).** Загрузить эту папку в репозиторий на GitHub.
Сборка запустится сама (Actions → Build Windows app), в результатах будут
`BohemiaPhotos.exe` (запускается сразу) и `BohemiaPhotos-Setup.exe` (установщик с ярлыком).

**Вариант 2, на своём Windows.** Поставить Python 3.12 с python.org (отметить «Add python.exe to PATH»),
дважды щёлкнуть `build_exe.bat`. Готовый файл: `dist\BohemiaPhotos.exe`.

## Запуск без сборки
    pip install -r requirements.txt
    python bohemia_gui.py

Из командной строки:

    python bohemia_photos.py ПРАЙС.xlsx ПАПКА_КАТАЛОГОВ [РЕЗУЛЬТАТ] [ИМЕЮЩИЕСЯ_ФОТО]
    python guzzini_photos.py ПРАЙС.xlsx ПАПКА_КАТАЛОГОВ [РЕЗУЛЬТАТ] [ИМЕЮЩИЕСЯ_ФОТО]
    python invoice_reader.py ОТЧЁТ.xlsx ДОК1.pdf [ДОК2.pdf ...] [--price ПРАЙС1.xlsx --price ПРАЙС2.xlsx]
