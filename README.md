# Bohemia Photos — программа с окном

В окне три вкладки:

1. **Bohemia — фото.** Прайс (.xlsx), папка с PDF-каталогами Bohemia, папка результата → «Запустить».
   Результат: папка `photos` (JPG по полному коду) и `report.xlsx` с миниатюрами и статусами.
2. **Guzzini — фото.** То же для каталогов и журналов Guzzini. Код в каталоге базовый (`281976`, `1793.00`),
   в прайсе к нему добавлен цвет (`28197682`, `179300156`). Если в каталоге есть образец нужного цвета,
   берётся именно он («фото цвета»), иначе общее фото товара («проверить цвет»). Читаются все листы прайса.
3. **Proforma / Invoice.** Добавить один или несколько PDF (или Excel-выгрузку заказа), при желании выбрать прайс,
   указать файл отчёта → «Запустить». В отчёте лист «Позиции» (код, описание, кол-во, цена, скидка, сумма,
   проверка кол-во × цена = сумма, сверка с прайсом) и лист «Документы» (номер, дата, валюта, сумма строк
   и итог документа). Код ищется в прайсе точно, по короткому коду Bohemia или по началу кода (Guzzini).

## Как получить .exe
**Вариант 1, GitHub (ничего не ставить на компьютер).** Загрузить эту папку в репозиторий на GitHub.
Сборка запустится сама (Actions → Build Windows app), в результатах будут
`BohemiaPhotos.exe` (запускается сразу) и `BohemiaPhotos-Setup.exe` (установщик с ярлыком).

**Вариант 2, на своём Windows.** Поставить Python 3.12 с python.org (отметить «Add python.exe to PATH»),
дважды щёлкнуть `build_exe.bat`. Готовый файл: `dist\BohemiaPhotos.exe`.

## Запуск без сборки
    pip install -r requirements.txt
    python bohemia_gui.py

Из командной строки:

    python bohemia_photos.py ПРАЙС.xlsx ПАПКА_КАТАЛОГОВ [РЕЗУЛЬТАТ] [ИМЕЮЩИЕСЯ_ФОТО]
    python guzzini_photos.py ПРАЙС.xlsx ПАПКА_КАТАЛОГОВ [РЕЗУЛЬТАТ] [ИМЕЮЩИЕСЯ_ФОТО]
    python invoice_reader.py ОТЧЁТ.xlsx ДОК1.pdf [ДОК2.pdf ...] [--price ПРАЙС.xlsx]
