## Bohemia Photos 1.1.0

Программа вырезает фото товаров Bohemia из PDF-каталогов по кодам из прайс-листа и собирает отчёт в Excel.

### Скачать
- **BohemiaPhotos-Setup.exe** — установщик (ярлык на рабочем столе и в меню «Пуск»).
- **BohemiaPhotos.exe** — запуск без установки.

Если Windows покажет «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае» (у программы нет цифровой подписи).

### Что умеет
- Окно: выбор прайса, папки с каталогами, папки с уже имеющимися фото (необязательно) и папки результата, прогресс и лог.
- Прайс: .xlsx, .xls, .xlsx с защитой «только для чтения», .csv.
- Коды в любом виде: `91L/1SJ60/0/00000/380-664`, `…/380`, `…/38`; берутся из колонок CODE, CODE SHORT, CODE W/O BN, CODE W/O ZERO; лишние пробелы и длинные тире не мешают.
- Сопоставление с каталогом по коду и сверка по описанию (тип и объём/размер); сомнительные строки помечаются «проверить».
- Имеющиеся фото ищутся по полному коду без учёта разделителей (`/ - – — _`), регистра и приписок; такие артикулы не вырезаются заново.
- Результат: папка `photos` (JPG, имя = код с `-` вместо `/`) и `report.xlsx` с фото прямо в ячейках (Excel 365/2024) и цветными статусами.
