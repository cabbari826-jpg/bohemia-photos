## Inventa 1.4.1

Программа вырезает фото товаров из PDF-каталогов по кодам из прайс-листа и разбирает Proforma / Invoice в Excel.

### Скачать
- **Inventa-Setup.exe** — установщик (ярлык на рабочем столе и в меню «Пуск»).
- **Inventa.exe** — запуск без установки.
- BohemiaPhotos-Setup.exe — тот же установщик под старым именем (нужен для автообновления версий 1.2.x).

Если Windows покажет «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае» (у программы нет цифровой подписи).

### Новое в 1.4.1
- **Новый вид программы** в стиле сайта: бирюзовая шапка, название рукописным шрифтом Courgette, шрифт Manrope, скруглённые карточки, поля и кнопки одного размера.
- **Живой интерфейс:** кнопки пружинят при нажатии, карточки и поля плавно подсвечиваются, поле при перетаскивании файлов «вдыхает», а при сбросе подпрыгивает — чем тяжелее файл, тем сильнее, раздвигая соседние поля. Новые строки в списке коротко вспыхивают.
- **Перетаскивание файлов мышью.** Документы, заказы и прайсы можно перетащить из Проводника прямо в списки (можно целую папку: добавятся файлы подходящих типов). В поля папок и «Куда сохранить» тоже можно перетащить папку.
- **Исправлены обновление и установка поверх старой версии.** Установщик сам закрывает программу, удаляет прежнюю версию (Bohemia Photos или Inventa) её деинсталлятором и ставит новую в папку пользователя, куда запись разрешена без прав администратора. Если старая версия стояла «для всех», Windows один раз спросит разрешение на её удаление.
- Автообновление из программы больше не откатывается из-за того, что программа ещё не успела закрыться. Если обновление всё же не встало, при следующем запуске программа скажет об этом и покажет конец журнала установки (%TEMP%\Inventa-update.log).

### Новое в 1.4.0
- **Сверка нашего заказа с документами поставщика.** На экране «Proforma / Invoice → Excel» появился список «Наши заказы поставщику»: туда добавляются Excel-заказы в том виде, в каком их отправляют (Reference / Description / Price / Quantity, бланки Le Creuset, Bormioli, Bohemia и др.; берутся строки с количеством больше 0). В отчёте лист «Сверка с заказом»: по каждому коду — кол-во и цена в заказе и в Proforma / Invoice и расхождение: нет в документах поставщика, лишнее (нет в заказе), кол-во меньше / больше, цена выше / ниже, код отличается. Если в документе указаны упаковки (8 наборов по 6 шт вместо 48 шт), это распознаётся и считается совпадением.
- Заказ можно сверить и только с прайсом (лист «Заказ»).

### Новое в 1.3.0
- Программа теперь называется **Inventa** (раньше Bohemia Photos). Обновление ставится поверх старой версии: в «Установке и удалении программ» остаётся одна запись, старые ярлыки «Bohemia Photos» заменяются на «Inventa». Настройки и результаты не трогаются.

### Новое в 1.2.1
- Своя иконка программы (exe, установщик, окно, ярлыки).
- Издатель программы — **Jooble Soft**: в установщике, в «Установке и удалении программ», в свойствах файла (Свойства → Подробно) и внизу стартового экрана.

### Новое в 1.2.0
- **Обновление из программы.** Установленная версия при запуске сама проверяет, вышла ли новая, и предлагает обновиться: скачивает установщик, ставит новую версию и открывает программу снова. Есть кнопка «Проверить обновления» на стартовом экране.
- Окно открывается по центру экрана и целиком на нём (учитывается масштаб Windows 125–150 %).
- **Сначала выбор действия:** «Proforma / Invoice → Excel» или «Фото из каталогов», у каждого свой экран и своя кнопка («Сделать Excel» / «Вырезать фото»).
- **Несколько прайс-листов сразу** — и для сверки документов, и для фото. Бренд прайса (Bohemia / Guzzini) определяется сам, каталоги разных брендов могут лежать в одной папке.
- **Proforma / Invoice → Excel.** PDF (и Excel-выгрузки заказов) превращаются в Excel-отчёт: код, описание, кол-во, цена, скидка, сумма; проверка «кол-во × цена = сумма» и сверка суммы строк с итогом документа. Проверено на документах Le Creuset, Allinox/Beka, BSD, Bormioli, Bohemia Crystal, Chilewich, Bugatti, Guzzini.
- **Сверка с прайсом.** Для каждой позиции: найдена ли в прайсе, цена прайса, разница и %, статус «цена совпадает / выше / ниже / нет в прайсе». Код ищется точно, по короткому коду Bohemia и по началу кода Guzzini (`1793.00` → `179300156`). Валюта колонки цены (EUR/USD) берётся по валюте документа.
- **Helios.** Прайс можно добавить прямо в PDF (Preisliste 83 D: 256 позиций, включая запчасти STO / EGL / GU). Сверка документов и Order List: `2941-001` находится в прайсе как модель `2941`. Фото из каталога Helios: для каждого кода с цветом подбирается фото этого цвета по образцу в таблице каталога; если такого фото нет — фото модели с пометкой «проверить цвет».
- **Фото Guzzini.** Каталоги и журналы Guzzini: базовый код товара + цвет из прайса; если в каталоге есть образец нужного цвета, сохраняется он. Фото берутся прямо из PDF, без подписей поверх. Читаются все листы прайса (GUZZINI, COOKWARE, HORECA).

### Что умеет (Bohemia, без изменений)
- Прайс: .xlsx, .xls, .xlsx с защитой «только для чтения», .csv.
- Коды в любом виде: `91L/1SJ60/0/00000/380-664`, `…/380`, `…/38`; берутся из колонок CODE, CODE SHORT, CODE W/O BN, CODE W/O ZERO.
- Сверка по описанию, пометка «проверить», учёт уже имеющихся фото.
- Результат: папка `photos` и `report.xlsx` с фото прямо в ячейках (Excel 365/2024) и цветными статусами.
