## Bohemia Photos 1.2.0

Программа вырезает фото товаров из PDF-каталогов по кодам из прайс-листа и разбирает Proforma / Invoice в Excel.

### Скачать
- **BohemiaPhotos-Setup.exe** — установщик (ярлык на рабочем столе и в меню «Пуск»).
- **BohemiaPhotos.exe** — запуск без установки.

Если Windows покажет «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае» (у программы нет цифровой подписи).

### Новое в 1.2.0
- **Сначала выбор действия:** «Proforma / Invoice → Excel» или «Фото из каталогов», у каждого свой экран и своя кнопка («Сделать Excel» / «Вырезать фото»).
- **Несколько прайс-листов сразу** — и для сверки документов, и для фото. Бренд прайса (Bohemia / Guzzini) определяется сам, каталоги разных брендов могут лежать в одной папке.
- **Proforma / Invoice → Excel.** PDF (и Excel-выгрузки заказов) превращаются в Excel-отчёт: код, описание, кол-во, цена, скидка, сумма; проверка «кол-во × цена = сумма» и сверка суммы строк с итогом документа. Проверено на документах Le Creuset, Allinox/Beka, BSD, Bormioli, Bohemia Crystal, Chilewich, Bugatti, Guzzini.
- **Сверка с прайсом.** Для каждой позиции: найдена ли в прайсе, цена прайса, разница и %, статус «цена совпадает / выше / ниже / нет в прайсе». Код ищется точно, по короткому коду Bohemia и по началу кода Guzzini (`1793.00` → `179300156`). Валюта колонки цены (EUR/USD) берётся по валюте документа.
- **Фото Guzzini.** Каталоги и журналы Guzzini: базовый код товара + цвет из прайса; если в каталоге есть образец нужного цвета, сохраняется он. Фото берутся прямо из PDF, без подписей поверх. Читаются все листы прайса (GUZZINI, COOKWARE, HORECA).

### Что умеет (Bohemia, без изменений)
- Прайс: .xlsx, .xls, .xlsx с защитой «только для чтения», .csv.
- Коды в любом виде: `91L/1SJ60/0/00000/380-664`, `…/380`, `…/38`; берутся из колонок CODE, CODE SHORT, CODE W/O BN, CODE W/O ZERO.
- Сверка по описанию, пометка «проверить», учёт уже имеющихся фото.
- Результат: папка `photos` и `report.xlsx` с фото прямо в ячейках (Excel 365/2024) и цветными статусами.
